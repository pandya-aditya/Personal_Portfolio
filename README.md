# Aditya Pandya — Local React Portfolio

This project is local-only. Do not publish, upload, or sync it to hosted Sites unless explicitly requested.

## Run locally

```sh
cd /Users/adityapandya/Documents/Personal-Website/portfolio
npm install
npm run dev
```

Open http://127.0.0.1:5173. No ChatGPT account or sign-in is required.

## Production build

```sh
npm run build
npm run preview
```

Content and interactions are in `src/main.jsx`; styling is in `src/style.css`. The updated résumé is in `public/resume.pdf`.

The `.openai/hosting.json` file records the previously created private hosted site solely for cleanup/history. It is not used by Vite and does not cause deployment.
